# homebrew-tap

Homebrew tap for CLIs by [dvaldivia](https://github.com/dvaldivia).

```sh
brew install dvaldivia/tap/tukituki
```

Or tap once and install by name:

```sh
brew tap dvaldivia/tap
brew install tukituki
```

## Formulae and casks

| Name | Kind | Description | Source |
| --- | --- | --- | --- |
| `tukituki` | formula | Terminal UI for managing multiple dev processes | https://github.com/dvaldivia/tukituki |
| `lasd` | cask | | https://github.com/dvaldivia/lasd |

Entries are updated automatically by each project's release workflow.
